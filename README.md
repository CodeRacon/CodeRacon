## Featured project: RoomFull

**RoomFull** is a production-deployed full-stack booking application for coworking spaces. I built it end to end—from product concept and user interface through data modelling and backend domain logic to deployment.

Key aspects include:

* role-based authentication and protected actions
* server-side validation of business rules
* availability checks and booking conflict prevention
* PostgreSQL with Prisma migrations
* OpenAPI documentation with Swagger UI
* separate production deployments for frontend and backend

[Live demo](https://roomfull.michael-buschmann.dev) · [Repository](https://github.com/CodeRacon/roomfull-2.0) · [API documentation](https://api.roomfull.michael-buschmann.dev/docs)
